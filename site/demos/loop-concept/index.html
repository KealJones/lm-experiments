Small model lab

Do small models know what a loop is, or just how to spell one?

Qwen3 0.6B and 1.7B write working loops in Python. So hand them a loop they already understand, in a language they've never seen, plus the syntax reference you'd look up. If knowing the idea is separate from knowing the spelling, that should be enough.

It isn't. With the reference in the prompt, the 1.7B model solved 5 of its 21 Python-solvable tasks in the made-up language. The 0.6B solved 1 of 22. Mostly they copied the reference's example instead of using it.

What it says

  
    
    
  • Both models have the loop concept: in Python they solve 21–22 of the 25 tasks.
    • 
    
  • A looked-up reference doesn't carry that concept into a new spelling. It roughly halves syntax failures, but
      those mostly turn into wrong output, not passes.
    • 
    
  • The models treat the reference as the answer to imitate, not a template to fill. Qwen3 0.6B pastes the
      reference's own example (list(3, 1, 4), "even") into 66% of its Plink answers, and the
      reference makes its plain Python worse (66% → 44%).
    • 
    
  • Qwen3 1.7B's Zig errors show the same gap: the reference says signed integers need @mod, and it
      still writes i % 2.
    • 
    
  • What the small models lack is a habit, not knowledge: noticing "I don't know this", going to look, and changing
      course after an error. Gemma 4 E2B has the last part. That's what the next experiments try to train.
    •
