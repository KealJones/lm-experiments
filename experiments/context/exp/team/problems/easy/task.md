# Problem: Second Largest Distinct Value

You are given N integers. Print the second largest *distinct* value among them.
If there are fewer than two distinct values, print -1.

## Input
The first line contains N (1 ≤ N ≤ 200000).
The second line contains N integers a_1 … a_N (−10^9 ≤ a_i ≤ 10^9), separated by spaces.

## Output
One integer: the second largest distinct value, or -1.

## Examples
Input:
5
3 1 4 1 5
Output: 4

Input:
3
7 7 7
Output: -1

Write the program as solution.py reading stdin and printing the answer.
