Plink language reference

## Overview

Plink is a small line-based programming language. Each statement is on its own line. Blocks (loops and ifs) are
closed with a line containing only `end`. Indentation is ignored but recommended. A Plink program is just a list of
statements: there is no main function. Integers and text are the only kinds of value, plus true/false and lists.

## Comments

A line starting with the word `note` is a comment.

    note this line is ignored

## Variables

`let` declares a new variable. `set` changes a variable that already exists. Using `set` on a name that was never
declared with `let` is an error, and so is declaring the same name twice with `let`.

    let total be 0
    let name be "plink"
    set total to total + 5

## Printing

`show` prints one or more values separated by spaces, followed by a newline.

    show total
    show "x is", 3
    show 1, 2, 3

prints

    5
    x is 3
    1 2 3

## Numbers and operators

Arithmetic: `+` `-` `*` and the words `div` (whole-number division, rounding down) and `mod` (remainder).

    show 17 div 5
    show 17 mod 5

prints 3 then 2.

Comparison: `=` (equal), `<>` (not equal), `<` `>` `<=` `>=`. Logic: `and`, `or`, `not`. Values `true` and `false`.
Parentheses group as usual. Note: `==`, `!=`, `%`, `//` and `**` are not Plink operators.

## Text

Text is written in double quotes. `&` joins two pieces of text. `text(n)` turns a number into text.

    let s be "ab" & "cd"
    show s & text(42)

prints `abcd42`.

## Lists

`list(a, b, c)` makes a list. `item(xs, i)` is the value at position i (positions start at 0). `size(xs)` is the
number of items. Lists can't be changed after they are made.

    let xs be list(10, 20, 30)
    show item(xs, 0), size(xs)

prints `10 3`.

## count loops

`count` runs a variable through a range of whole numbers. Both ends are included. `by` sets the step and may be
negative; without `by` the step is 1.

    count i from 1 to 5
      show i
    end

prints 1 2 3 4 5, one per line.

    count i from 10 to 0 by -5
      show i
    end

prints 10, 5, 0.

## for each loops

`for each` runs a variable over the items of a list.

    for each x in list(3, 1, 4)
      show x
    end

`for each index` runs a variable over the positions 0 .. size-1 of a list.

    let xs be list(7, 8)
    for each index k in xs
      show k, item(xs, k)
    end

prints `0 7` then `1 8`.

## while loops

`while` repeats while its condition is true.

    let n be 1
    while n < 100
      set n to n * 3
    end
    show n

prints 243.

## stop

`stop` leaves the innermost loop immediately.

    count i from 1 to 10
      if i = 4
        stop
      end
      show i
    end

prints 1, 2, 3.

## if, orif, otherwise

    if n mod 2 = 0
      show "even"
    orif n = 1
      show "one"
    otherwise
      show "odd"
    end

Conditions must be true or false.

## Errors

A line Plink can't read gives `syntax error: line N: ...`. Runtime problems (an item position out of range,
joining text to a number without text(), a condition that isn't true/false) give `runtime error: ...`.
